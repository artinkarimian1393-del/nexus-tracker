# NEXUS TRACKER

نسخه آغازینِ شفاف برای ساخت لینک هدایت و آمار کلیک با رضایت بازدیدکننده.

## قابلیت‌ها
- ساخت لینک کوتاه/اختصاصی برای مقصدهای HTTP و HTTPS
- نمایش صفحه اطلاع‌رسانی پیش از هدایت
- ثبت IP، زمان و User-Agent فقط پس از تیک‌زدن رضایت و فشردن دکمه ادامه
- داشبورد محافظت‌شده با رمز مدیر
- استعلام دستی IP از سرویس عمومی RDAP و نمایش JSON خام
- حذف کلیک یا لینک از داشبورد

## اجرای محلی
1. Python 3.10 یا جدیدتر نصب کن.
2. در پوشه پروژه اجرا کن:
   `pip install -r requirements.txt`
3. متغیرهای محیطی را تنظیم کن:
   - `SECRET_KEY`: یک رشته تصادفی و محرمانه
   - `ADMIN_PASSWORD`: رمز قوی مدیر
4. اجرا:
   `python app.py`
5. آدرس `http://127.0.0.1:5000` را باز کن.

## انتشار در Render
1. یک مخزن GitHub جدید و مستقل با نام `nexus-tracker` بساز.
2. همه فایل‌های این ZIP را در ریشه مخزن آپلود و Commit کن.
3. در Render گزینه New > Blueprint را انتخاب و مخزن را متصل کن.
4. هنگام ساخت سرویس، مقدار محرمانه `ADMIN_PASSWORD` را تعیین کن.
5. Render از `render.yaml` استفاده می‌کند. دیسک پایدار برای SQLite تعریف شده است.

## نکات حریم خصوصی و امنیت
- صفحه رضایت قبل از ثبت هر بازدید نشان داده می‌شود؛ این متن را متناسب با قوانین محل فعالیت و سیاست حریم خصوصی خودت تکمیل کن.
- IP و User-Agent داده شخصی محسوب می‌شوند. فقط در صورت داشتن مبنای قانونی، اطلاع‌رسانی مناسب و ضرورت جمع‌آوری استفاده کن؛ دوره نگهداری و روش تماس/درخواست حذف را مشخص کن.
- به‌صورت پیش‌فرض IP خام در دیتابیس ذخیره می‌شود تا گزارش مدیر کار کند؛ آن را عمومی نکن و دسترسی مدیر را محدود نگه دار.
- برای Render، `DATABASE_PATH=/var/data/tracker.db` و دیسک پایدار تنظیم شده است.
- پشت پراکسی، برنامه عمداً به هدرهای Forwarded اعتماد نمی‌کند؛ بنابراین ممکن است IP ثبت‌شده، IP پراکسی باشد. برای جلوگیری از جعل IP این رفتار را تغییر نده مگر با پیکربندی دقیق پراکسی مورد اعتماد.
- RDAP اطلاعات ثبت‌شده درباره تخصیص شبکه/سازمان را می‌دهد، نه هویت قطعی یا نشانی منزل کاربر.
- این پروژه ردیابی پنهانی، fingerprinting، موقعیت‌یابی دقیق یا دور زدن رضایت ندارد.
- قبل از استفاده واقعی، HTTPS، سیاست حریم خصوصی، CSRF، محدودیت درخواست، پشتیبان‌گیری و بررسی امنیتی اضافه کن.
